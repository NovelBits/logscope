# @novelbits/ble-spec

Bluetooth LE specification reference data: error codes, company identifiers,
and (in later phases) UUIDs, AD types, and the GATT Specification Supplement.

This is **Phase 1 of the BLE spec database**: data lives in YAML files under
`data/`, TypeScript wrappers are generated by `scripts/generate-wrappers.ts`,
and the package is consumed by LogScope via a tsconfig path alias.

Later phases extract this to a standalone OSS repo, add Python bindings,
mirror the Bluetooth SIG bitbucket YAML, and layer a private vendor-quirks
package on top.

## Structure

```
packages/ble-spec/
├── data/
│   ├── novel-bits-curated/   YAML source of truth (we maintain)
│   │   ├── hci_error_codes.yaml
│   │   ├── att_error_codes.yaml
│   │   ├── smp_error_codes.yaml
│   │   └── company_identifiers.yaml
│   └── sig-mirror/           (empty for Phase 1; Phase 3 mirrors SIG bitbucket)
├── scripts/
│   └── generate-wrappers.ts  Reads YAML, emits TS modules
├── src/
│   ├── types.ts              Shared types (ErrorCodeEntry, etc.)
│   ├── index.ts              Public re-export surface
│   └── generated/            TS modules generated from YAML (committed)
└── tests/                    Round-trip and generator tests
```

## Regenerating

After editing any YAML file:

```bash
npm run gen:ble-spec
```

CI verifies that the committed generated files match the YAML; drift fails the build.
