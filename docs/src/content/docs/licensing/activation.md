---
title: License Activation
description: How to activate a LogScope license
---

The LogScope license system is not yet active. All features are currently available to all users at no cost.

When the Pro tier launches, this page will document how to enter a license key, manage your license, and activate Pro features.

License-related commands exist in the Command Palette (`LogScope: Enter License Key`, etc.) but are reserved for future use and have no effect in the current version.
